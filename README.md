# DENV_In_Vivo
This repository contains the data and source code files used to obtain the results described in the paper "Estimating the in vivo prophylactic effect of mosnodenvir, a novel dengue antiviral, on DENV-2 infection".

The code was developed using Visual Studio 2022 and all output from the model is saved in .csv files.

Fixed parameter values can be inputted by reading in values from a file such as Param_Values_NHP.txt, and parameters to be estimated are specified in a file such as Fit_Params_NHP.txt. The 'Data' folder contains the following files:

Mice_Data.txt (mice data used for model fitting)
NHP_Data.txt (NHP data used for model fitting)
